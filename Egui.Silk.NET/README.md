# Egui.Silk.NET

This crate provides a base class for integration between [Egui.NET](https://github.com/DouglasDwyer/Egui.NET) and [`Silk.NET`](https://github.com/dotnet/Silk.NET).

This library translates Silk events to Egui, handles copy/paste, etc. This library **does not** handle rendering: see [Egui.Silk.NET.OpenGL](/Egui.Silk.NET.OpenGL/) for that.
